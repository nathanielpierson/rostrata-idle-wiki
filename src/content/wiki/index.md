# Rostrata Idle Wiki

Welcome. This wiki is built from Markdown files in `src/content/wiki/`.

## Adding a page

1. Create a new file: `src/content/wiki/your-page-name.md`  
   (Use lowercase and hyphens, e.g. `woodcutting.md`.)

2. Start with a top-level heading:

   ```markdown
   # Your title
   ```

3. Save — the sidebar lists all `.md` files automatically.  
   **Home** is always `index.md` (this page).

## Linking between pages

Use normal Markdown links with paths:

- [Example topic](/example-topic)

External sites use full URLs and open in a new tab.

## Tips

- **GitHub-flavored Markdown** is enabled (tables, strikethrough, task lists, etc.).
- After adding a file, the dev server will hot-reload.
